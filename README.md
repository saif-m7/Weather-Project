# WeatherNow 🌤️

WeatherNow is a modern and responsive weather application built with React and Vite.  
It provides real-time weather information, hourly and 7-day forecasts, weather highlights, and temperature trends.  
The application also includes location-based weather, favorites, recent searches, dark/light mode, and dynamic weather animations.  
Built with a clean and interactive UI for a smooth weather-checking experience.

🔗 **Live Demo:** https://weather-app-three-gray-15.vercel.app/

## Features

- Search weather by city
- Current location weather
- Current weather details
- Hourly forecast
- 7-day forecast
- Weather highlights
- Sunrise & sunset
- Temperature chart
- Favorite cities
- Recent searches
- Dark & light mode
- Dynamic weather animations
- Responsive design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- Framer Motion
- Recharts
- React Icons
- Open-Meteo API
